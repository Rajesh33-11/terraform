## What is Infrastructure ? 
**Infrastructure** means the **basic things you need to run something **
Everything needed to run applications, such as:
** - Servers  
- Networking (VPC, Subnets, Route tables)
- Storage (S3)
- Databases (RDS)
- Load Balancers
- Security (IAM, Security Groups)**
These things help your application run smoothly.

## What is Terraform?
Terraform is an Infrastructure as Code (IaC) tool created by HashiCorp.
It allows you to create, manage, and destroy AWS resources using code instead of clicking in the AWS console.
____________________________________________________________________
# Why Do We Use Terraform?
Here are the real-world uses:
- **✔ 1. Automates AWS infrastructure**  : Create EC2, S3, VPC, Load Balancers, RDS — everything with code.
- **✔ 2. Makes deployments repeatable**  :  Same configuration can be deployed in Dev, QA, Prod.
- **✔ 3. Version control**  : You can store your code in GitHub and track every change.
- **✔ 4. Works with all cloud providers**  : AWS, Azure, GCP, Oracle, Kubernetes… one tool for everything.
- **✔ 5. Avoid manual mistakes**  : Instead of clicking many steps, Terraform does it perfectly.
